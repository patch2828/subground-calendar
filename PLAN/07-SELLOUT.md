## 6. The scarcity mechanics — use the blueprint's own

The DREAM blueprint already contains a proven sellout structure. **Apply it to the club shows now, not just the festival:**

1. **Waitlist first, nothing for sale.** A data trap that costs nothing and builds the list.
2. **Tier 1, genuinely capped, priced to sell out fast.** Scarcity only works if the cap is real. A tier that never sells out teaches people to wait.
3. **Tier 2 opens on Tier 1 selling out** — the sellout is itself the announcement.
4. **Tier 3 / door price last.**

Gold Rush already has the shape: Early Bird $15 capped at 100, GA $20. **The 100 has to actually run out and be seen to run out.**
