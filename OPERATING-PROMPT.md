## Why the prompt is shaped this way

**It front-loads the read order, because the failure mode is always a stale fact, never a missing one.** CORE-STATE was five days behind the sidecars when I loaded it today; the sidecars had the card freeze, the paid GALLIUM deposit, the retired afters, TIFF's real handle, and the fact that his phone works again. A session that reads only core memory would have told him his phone was dead and his lineup was contract-gated. Both wrong, both confidently wrong.

**It puts R0 first,** because every other rule is a prohibition and prohibitions have no clock. R0 has one: the handoff.

**It names the never-list before the mission,** so speed never gets to argue with values. He asked for lightspeed and he asked for values in the same sentence. The order in the prompt is the answer to that: the values are the constraint, the speed is the objective function inside it.

**It ends by telling me to act, not to report.** He does not want a status meeting. He wants the thing done and one line about it.
